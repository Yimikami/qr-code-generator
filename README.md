# QR Code Generator

Generate stylish QR codes with logo embedding and customization.

## Features

- Live preview as you type
- Multiple content types (URL, Wi-Fi, Email, SMS, vCard)
- Logo upload (drag & drop) + popular brand presets
- Dot shape, corner frame, and corner dot style options
- Color customization with hex input and gradients
- Transparent background support
- Export as PNG, SVG, or copy to clipboard
